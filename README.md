Am dezvoltat un sistem de viziune artificială pentru siguranța rutieră, cu două componente:  detectarea benzilor și recunoașterea indicatoarelor.
Am folosit tehnologii moderne: procesare imagini, rețele neuronale, TensorFlow Lite. Sistemul l-am implementat pe o platformă embedded accesibilă.
Detectarea benzilor s-a realizat prin: conversii de culoare, filtre, Canny, sliding window. 
Recunoașterea indicatoarelor a fost posibilă în timp real prin clasificare live și afișare pe ecran LCD.
Demonstrează că soluții eficiente pot fi realizate și pe hardware cu resurse limitate.
